# Quick task: Taskbar visibility and close behavior

Gathered: 2026-10-02
Status: Ready for planning

## Task boundary

Show the running app in the desktop taskbar/dock while the panel is open. Add a persisted setting choosing close to tray or quit, defaulting to close to tray.

## Decisions

- User explicitly requested tray as the default and both close behaviors.
- User confirmed application launcher line means the running-app taskbar/dock while open.
- Apply the preference to the native Close action from either panel or Settings. CAP-14 focus loss and hotkey dismissal keep hiding the panel.
- Keep the precreated window, prevent native destruction, and route quit through ordered daemon shutdown.
- Settings and external config edits use the existing ConfigStore. Older config files adopt the tray default.
