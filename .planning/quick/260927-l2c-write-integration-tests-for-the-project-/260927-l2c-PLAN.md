# Quick Plan: Integration tests and 80% coverage gate

Baseline from `flutter test --coverage --branch-coverage --exclude-tags=live test`: 1,147 passing tests, 83.17% line coverage (3,460/4,160) and 76.96% branch coverage (1,443/1,875) across instrumented handwritten `lib/` files. The report contains `BRDA` records but no `BRF`/`BRH` summary records, so the gate must count `BRDA` directly. Some platform rows skip without a desktop session.

## Task 1: Integrate the main user journey

**files:** `test/integration/daemon_workflow_test.dart`

**action:** Add a Flutter widget integration flow over the production daemon app and controller providers with fake hotkey, clipboard, provider, and history ports. Check edited input, streamed variants, persistence, explicit copy, and panel visibility.

**verify:** Run the new test file with `flutter test`.

**done:** The flow crosses component boundaries and cites the relevant CAP IDs.

## Task 2: Exercise the configured HTTP provider

**files:** `test/integration/openai_compatible_flow_test.dart`

**action:** Drive the real OpenAI-compatible adapter against a loopback SSE server. Cover a successful structured stream, stateless repeat, failures, cancellation, validation, and timeouts. Add cases guided by the baseline branch gap.

**verify:** Run the new test file with `dart test`; inspect the updated branch totals.

**done:** The adapter's user-visible success and failure flows are tested through its public interface.

## Task 3: Enforce coverage in CI

**files:** `tool/check_coverage.dart`, `test/integration/coverage_gate_test.dart`, `.github/workflows/ci.yml`

**action:** Implement a strict LCOV gate with a transparent handwritten-source filter and 80% thresholds for lines and branches; test rejection of missing and under-threshold data. Update workflow triggers and run the full Flutter test suite with coverage.

**verify:** `dart analyze --fatal-infos`; `flutter test --coverage --branch-coverage --exclude-tags=live test`; `dart run tool/check_coverage.dart coverage/lcov.info`.

**done:** CI configuration has the requested branch filters and the local gate passes both actual measured totals.
