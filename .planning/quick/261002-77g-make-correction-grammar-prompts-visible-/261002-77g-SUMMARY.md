# Editable correction prompts

Implemented the user's selected layout: each preset references a plain UTF-8 .txt file beside config.json through systemPromptFile. Fresh installs seed the full shipped default prompt; existing inline strings migrate preserving exact text, model, provider and other settings. Existing default text survives reseeding a deleted config, unrelated files are not overwritten, and custom filenames survive subsequent Settings writes.

Settings now displays a multiline Correction prompt editor. Save writes through ConfigStore into the same file; directory watching publishes external text edits to Settings and the composition root. Clean editors follow committed edits; dirty drafts remain with a conflict notice. A save refuses an active preset or prompt that changed before the UI showed it, while an explicitly reviewed conflict can be saved. Expected failures remain rendered values and Retry is available by saving again.

File references stay private to infrastructure; domain Preset still binds the resolved prompt and model. Blank, missing, malformed, ambiguous and shared prompt sources are rejected. Replacements are privately staged before installation, with rollback after installation failure. The shipped prompt wording and provider/history contracts are unchanged.
