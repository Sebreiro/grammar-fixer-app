# Quick Task 261002-77g: Editable correction prompts

Gathered: 2026-10-02
Status: Ready for planning

## Task boundary
Make correction grammar prompts visible and editable in the config, with populated defaults on first run.

## Decisions
- The user authorizes either config storage or a separate file beside it.
- User selected separate .txt files beside config.json: plain multiline text referenced by each preset through systemPromptFile. This is the locked layout decision.
- New configs contain a preset pointing at the complete shipped prompt in its own .txt file. Migrate existing inline strings preserving their exact text and settings. Seed defaults only when absent, preserving existing prompt files.
- Settings must expose the active preset prompt and write through ConfigStore, because the SPEC requires both editing surfaces to stay synced.
- Keep the existing default prompt, output protocol, provider interface, history schema and state management.
