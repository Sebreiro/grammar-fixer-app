## The hazard that will bite

`test/architecture/runtime_checklists_test.dart` **pins this prose**. Read its head doc before
touching a single skip reason. Specifically it asserts:

- `_pointers` — six suites, each of whose skip reason must name its procedure's path. Lose the
  clause and the row fails.
- `_Citation` — the step numbers each clause cites, checked **in the order the clause cites them**,
  and each number resolved against the procedure's own `*Settles:*` line.
- `_Procedure.notCoveredHere` — phrases the procedure's "Not covered here" section must keep naming,
  because skip clauses route claims to them.

So an edit that rewrites a sentence containing a pointer clause or a cited step number must either
preserve it exactly or update the pin in lockstep. Prefer preserving: this plan is not the place to
renumber a checklist, and the head doc explains that inserting a step misdirects every citation
below it.

something that lies:

- It counts deletions with `git diff --numstat`, **not** by grepping the diff for `^-`. A deleted
