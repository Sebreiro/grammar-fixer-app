# Project Retrospective

## Milestone: v1.0 — Ledger Hardening

**Shipped:** 2026-09-26

**Phases:** 2

**Plans:** 53
**Tasks:** 100

### What Was Built

- Truthful X11 and Wayland hotkey results, including a typed retained shortcut after a refused Wayland rebind.
- Settings, tray, panel, and teardown behavior reconciled with the shipped daemon; a second correction provider is selectable.
- A current 19-decision architecture spine and evidence-qualified closure of the 40 Phase 02 ledger mappings.

### What Worked

- The milestone integration audit found the Wayland retained-refusal gap that the first phase verification missed. Plans 02-27 and 02-28 then closed it with an explicit owner decision and focused existing-row proof.
- Three-source requirement reconciliation found all 50 IDs in traceability, summaries, and phase verification before archive.
- Local analyzer and existing Dart/Flutter suites passed on the final code tree.

### What Was Inefficient

- The initial retained-refusal behavior answered as an ordinary bound result; the refusal marker and config-seed rule needed a late closure cycle.
- An attempted external Claude generator route caused an avoidable authentication and trust interruption. The frozen-record update was completed locally with Codex.
- The milestone's deliberate no-new-test scope leaves eight Phase 02 live checks and five joined behavior truths unobserved.

### Patterns Established

- A rebind result distinguishes a new binding from a rejected replacement that leaves the old shortcut active.
- Frozen architecture updates start from the append-only memlog and committed source, preserve AD identifiers, and state what live behavior remains unobserved.
- A waiver changes progression status without changing the underlying evidence claim.

### Key Lessons

1. Verify the complete Settings → config → tray flow when a backend can retain prior state after refusing a mutation.
2. Keep source-level, modeled-test, and live-desktop evidence separate in phase and milestone reports.
3. Use the authorized local generator workflow unless the user specifically needs an external service.

### Cost Observations

Model mix and session count were not measured for this milestone. The recorded plan count is 53; the late retained-refusal closure used two additional plans.
